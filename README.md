# OpenReport
User reporting system for game &amp; chat platforms. Prevent cheating, spam and profanity. Built with [Svelte](https://svelte.dev).

## Backend

The [OpenReport Backend](https://github.com/therealPaulPlay/OpenReportBackend) lives in its own repository.

## Developing with Svelte

Once you've installed dependencies with `npm install` (or `pnpm install` or `yarn`), start a development server:

```bash
npm run dev
```

## Building

To create a production version of the app:

```bash
npm run build
```

The production build can be previewed via `npm run preview`.

> To deploy OpenReport, an [adapter](https://svelte.dev/docs/kit/adapters) for your target environment may be needed.
